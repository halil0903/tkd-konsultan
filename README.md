# tkd-konsultan
TKD DİJİTAL KARDİYOLOJİ VE YAPAY ZEKA GRUBU İLE BİRLİKTE GELİŞTİRİLEN KONSULTAN UYGULAMASI
TKD Dijital Sağlık ve Yapay Zekâ Çalışma Grubu olarak geliştirdiğimiz TKD Konsültan uygulaması kullanıma sunulmuştur.

Uygulamamız; 2022 ESC Nonkardiyak Cerrahi Kılavuzu temel alınarak geliştirilen klinik karar destek sisteminin yanı sıra, kardiyoloji pratiğinde kullanılan birçok skorlama aracını içeren TKD Hesap modülünü de bünyesinde barındırmaktadır.
